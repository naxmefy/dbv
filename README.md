# dbv

A terminal database client – think DBeaver for the terminal, with a lazygit-style UI.

> **Status: alpha / under construction.** Nothing is usable yet. Expect breaking changes and missing features.

## Supported databases

- SQLite – planned for v0.1, the first release
- PostgreSQL, MySQL and more – planned after v0.1

See the [roadmap](https://dbv.nax.me/roadmap.html) for details.

## Installation

Pre-built binaries will be published on [GitHub Releases](https://github.com/naxmefy/dbv/releases) once the first release is out.
