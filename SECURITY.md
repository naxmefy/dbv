# Security Policy

## Supported versions

Only the latest minor version receives security fixes.

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities.

Preferred: use "Report a vulnerability" in the [Security tab](https://github.com/naxmefy/dbv/security) of the repository (private vulnerability reporting).
Alternatively, email [dbv@nax.me](mailto:dbv@nax.me).

dbv is maintained as a hobby project, so responses are best effort.
